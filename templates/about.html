Statistical DPS Model

White-Box · Explainable
What is it?

A hierarchical composite index that combines 14 software engineering metrics into a single Developer Productivity Score (DPS) between 0 and 1.

How does it work?
  1. Feature Engineering — 3 AI behavioral features are computed from raw metrics.
  2. Normalization — RobustScaler centers and scales all features.
  3. Polarity Inversion — Negative features (e.g., "longer time = worse") are flipped so higher = better.
  4. Entropy Weighting — Shannon entropy determines each feature's importance within its dimension.
  5. Hierarchical Aggregation — 5 dimension scores are averaged equally to produce DPS.
Key Strengths
  • Fully transparent — every weight and formula is visible
  • No training required — weights are computed analytically
  • Grounded in established methodology (OECD Composite Indicators Handbook)
  • Can explain exactly why a PR scored high or low
Formula
DPS = (TES + CQS + CLS + AIS + RCS) / 5

XGBoost ML Model

Black-Box · Machine Learning
What is it?

A gradient-boosted decision tree ensemble that learns to predict DPS from the same features. Trained on 22,258 Pull Requests.

How does it work?
  1. Same Preprocessing — log1p, percentile clipping, scaling.
  2. Training — XGBoost builds hundreds of decision trees sequentially, each correcting the errors of the previous.
  3. Prediction — New input passes through all trees; their outputs are summed.
Key Strengths
  • Extremely accurate — R² = 0.998 (99.8% variance explained)
  • Captures non-linear relationships
  • Fast inference
  • Industry standard for tabular data
Limitation

Cannot explain why a specific score was produced. Feature importance shows which features matter globally, but not the exact formula for any single prediction.

Why Compare Both?

This application demonstrates a core principle in data science: the interpretability–accuracy tradeoff.

Statistical Model — prioritizes interpretability. A researcher can trace every decimal point back to a formula. This is essential for academic publications where reviewers must verify methodology.
XGBoost Model — prioritizes predictive accuracy. In a production environment where you need to score thousands of PRs per second, XGBoost can replicate the statistical formula without running the full pipeline.

In this research, both models produce nearly identical outputs (Δ ≈ 0.004), proving that the statistical framework is learnable by ML — a powerful validation of the entropy-weighted methodology.
